🖥️ Project Overview
EliXa – Modern Tech Landing Page
This project is a sleek, responsive landing page for showcasing premium tech products like the iPhone 16 Pro Max. Built using HTML, CSS, and JavaScript, the design emphasizes minimalism, performance, and user engagement.

🔥 Key Features
🧭 Navigation Bar: Smooth and simple menu with sections like Home, Category, About, Gallery, Support, and a prominent Contact button.

📱 Hero Section: Bold headline promoting the iPhone 16 Pro Max with engaging typography and a strong call-to-action button (“Order Now”).

🖼️ Product Display: High-quality product image that draws user attention and elevates the brand's look.

💡 Modern Design: Clean layout, excellent use of whitespace, responsive font, and color balance for a professional user experience.

📌 Technologies Used
HTML5

CSS3

JavaScript

🗂️ Category Section
The Category section of the Elixa landing page showcases a clean and organized product filter system. Users can browse multiple tech product categories, including Smartphones, Laptops, Smartwatches, and Others. The interface uses a tabbed layout to allow smooth switching between product types without reloading the page. Each product is displayed with a high-quality image and clear product name for instant recognition.

This section improves user experience by making navigation intuitive and visually appealing, while preparing the page for dynamic product content integration in future updates.

🛍️ About Section
The About section highlights EliXa's mission as a trusted electronics destination. It introduces users to the brand’s commitment to delivering high-performance gadgets—from flagship smartphones to essential tech accessories. Visually complemented by a real-world store image, the section builds credibility and connection. Key offerings like 100% genuine products, fast delivery across India, dedicated support, and secure payments are clearly listed with intuitive icons. The section concludes with a value-driven statement, emphasizing EliXa’s role as a digital lifestyle partner for students, professionals, and tech enthusiasts alike.

🛒 Order Section
The Order section lets customers quickly reserve accessories directly from the landing page. It features a bold “Book Your Accessories” heading and an eye‑catching “Order Here” graphic on the left. On the right, there’s a clean, user‑friendly form with fields for:

Name, Email, Phone

Preferred Delivery Date

Product Name, Quantity

Delivery Location

A bright red “Confirm Now” button completes the flow, making it clear and straightforward for users to submit their order requests. This section is ready to be wired up to your backend or email‑service API to capture leads and streamline accessory orders.

📞 Support Section
The Support section of Elixa provides users with clear and accessible contact information for any queries or assistance. It displays four main contact details in a modern card layout — Address, Call Us, Email Us, and Opening Hours. Each card uses bold icons and contrasting red-and-white styling for easy visibility. The footer reiterates the same details and adds social media links, making it easy for users to stay connected. This section reinforces user trust and convenience by ensuring help is just a click away.
